Best Free Hosting Options for Your Alliance

Because this calculator is built as a single, self-contained HTML file, you can host it for 100% free forever with zero server maintenance. Here are the top 3 recommended options:

⭐ #1 Recommended: Netlify Drop Easiest (30 seconds)

  1. Rename this downloaded file to index.html and place it inside an empty folder.
  2. Go to app.netlify.com/drop in your browser.
  3. Drag & drop the folder onto the screen.
  4. Done! Netlify gives you an instant live URL (e.g., https://last-asylum-duel.netlify.app) that you can share directly with your alliance.

Option 2: GitHub Pages (Permanent & Custom Domain)

  1. Create a free account on github.com and create a new public repository (e.g., alliance-duel).
  2. Upload this file as index.html.
  3. Go to Settings → Pages, select branch main, and click Save.
  4. Your site will be live at https://yourusername.github.io/alliance-duel/.

Option 3: Cloudflare Pages / Vercel

Connect your GitHub repository to Cloudflare Pages or Vercel for enterprise-grade global CDN delivery, unlimited bandwidth, and automated updates whenever you edit task values.
